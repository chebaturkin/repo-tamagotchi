# промпт для агента: repo tamagotchi

сделай публичное client-side приложение repo tamagotchi, которое превращает структуру github-репозитория в маленького питомца с характером. человек вводит публичную ссылку вида `github.com/owner/repo` или загружает zip/папку через drag-and-drop. для ссылки используй только публичный архив без токена; при cors, лимите, приватном репозитории или другой ошибке сразу предложи zip.

разбери в браузере количество файлов, расширения, языки, примерный объём, README, лицензии, package manifests, тесты и конфиги. игнорируй `.git`, `node_modules`, сборочные каталоги и бинарные файлы. по прозрачной детерминированной формуле рассчитай 4–5 характеристик: энергия, любопытство, устойчивость, хаос, опыт. рядом объясни, какие реальные сигналы дали каждую характеристику. не выдумывай историю коммитов, если её нет в архиве.

покажи оригинального svg-питомца уже на первом экране и добавь локальный пример. после анализа покажи его состояние, найденные сигналы и дату. добавь повторный анализ, сброс, экспорт png/svg и share-снимок через hash адреса без базы. пустой или битый архив должен давать ясную ошибку с понятным следующим шагом.

## голос и визуальный принцип

пиши спокойно и по делу, по правилам авторского профиля Тимофея Чебатуркина. начала предложений, название проекта, названия сервисов, инструментов и технологий в прозе пиши строчными. имена людей, код, команды, пути, файловые идентификаторы и точные цитаты сохраняют нужный регистр. не обещай оценку качества проекта, если считаешь только структуру.

визуал: тёплый бумажный фон, крупный питомец и свободные отступы. fraunces и literata — для названий, onest — для текста, azeret mono — для метрик и кода. палитра: ink `#183a37`, paper `#f5efdf`, marigold `#e4a84a`, coral `#c95a4a`. не добавляй надзаголовки, подписи про полевой журнал, заметки на полях или декоративные слоганы. кнопки не касаются соседних полей; шапка и форма адаптируются к ширине 320 px.

## границы

- статический сайт для github pages;
- без api-ключей, платных сервисов, обязательного backend, серверной базы, авторизации и внешней ai-модели;
- пользовательские файлы обрабатываются только в браузере;
- при проблемах с внешним адресом остаётся полноценный локальный сценарий через zip или папку;
- проверяй desktop/mobile, клавиатуру, focus, reduced motion, пустые состояния и понятные ошибки;
- readme показывает реальные скриншоты, объясняет формат ссылки, локальный режим, формулу, приватность и публикацию.
