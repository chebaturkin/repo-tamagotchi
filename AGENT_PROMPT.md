# промпт для агента: Repo Tamagotchi

сделай публичное client-side приложение, которое превращает структуру GitHub‑репозитория в маленького питомца с характером. человек вводит публичную ссылку вида `github.com/owner/repo` или загружает ZIP/папку через drag-and-drop. для ссылки используй только публичный архив без токена; при CORS, лимите, приватном репозитории или другой ошибке сразу предложи ZIP.

разбери в браузере количество файлов, расширения, языки, примерный объём, README, лицензии, package manifests, тесты и конфиги. игнорируй `.git`, `node_modules`, сборочные каталоги и бинарные файлы. по прозрачной детерминированной формуле рассчитай 4–5 характеристик: энергия, любопытство, устойчивость, хаос, опыт. рядом объясни, какие реальные сигналы дали каждую характеристику. не выдумывай историю коммитов, если её нет в архиве.

покажи оригинального SVG‑питомца, его состояние, найденные сигналы и дату локального анализа. добавь повторный анализ, сброс, экспорт PNG/SVG и share‑снимок через URL hash без базы. пустой или битый архив должен давать ясную ошибку с понятным следующим шагом.

## голос и визуальный принцип

пиши коротко, спокойно и по делу. начала русских предложений делай строчными; собственные имена и технические обозначения (`GitHub`, `ZIP`, `README`, `SVG`, `PNG`, `CI`) сохраняй. не обещай оценку качества проекта, если считаешь только структуру.

вайб: карманный террариум и полевой журнал. Fraunces — для названий, Azeret Mono — для метрик и кода. палитра: ink `#183A37`, paper `#F3E8D2`, marigold `#E4A84A`, coral `#C95A4A`, muted `#6E7C70`. используй прямоугольные панели, тонкие правила, заметки на полях и одну векторную фигурку. не добавляй неоновые свечения, стекло, декоративные баблы и типичный SaaS‑дашборд.

## границы

- статический сайт для GitHub Pages;
- без API‑ключей, платных сервисов, обязательного backend, серверной базы, авторизации и внешней AI‑модели;
- пользовательские файлы обрабатываются только в браузере;
- при проблемах с внешним URL остаётся полноценный локальный сценарий через ZIP или папку;
- проверяй desktop/mobile, клавиатуру, focus, reduced motion, пустые состояния и понятные ошибки;
- README объясняет формат ссылки, локальный режим, формулу, приватность и бесплатный деплой.
